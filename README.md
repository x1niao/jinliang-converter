# 斤两换算（Android）

旧制重量单位「两」与现代「两」的实时换算 APP，并附带「钱」的换算与重量单位演化资料。

## 换算关系

| 项目 | 旧制 | 现制 |
|---|---|---|
| 1 斤 | 16 两 | 10 两 = 500 克 |
| 1 两 | 31.25 克 | 50 克 |
| 1 钱 | 3.125 克 | 5 克 |

- 旧两 → 现两：`现两 = 旧两 × 0.625`
- 钱制：**1 两 = 10 钱**（唐代确立，古今同）
- 例：旧 8 两（半斤）= 现 5 两 = 250 克 = 80 旧钱 = 50 现钱

## 制度交割

- **1929/1930 年**：《中华民国度量衡法》定 1 市斤 = 500 克，但仍为 16 两（1 两 31.25 克）
- **1959 年 6 月 25 日**：国务院命令改 16 两 1 斤为 10 两 1 斤（1 两 50 克），中医处方豁免
- **1979 年 1 月 1 日**：中医处方改用克，十六两制与「钱」彻底退出实际使用

## 功能

- 输入旧两数值，实时自动换算出现两、克数、旧钱、现钱
- 支持反向模式（现两 → 旧两）
- 斤两表示自动换算（如 0 斤 8 两 0 钱）
- 内置「参考资料及文献」离线页面，完整收录重量单位「两」「钱」的演化考证与 18 条文献

## 安装

下载 [`斤两换算.apk`](斤两换算.apk) 传到手机，点击安装（需允许「安装未知来源应用」）。

- 最低 Android 版本：5.0（API 21）
- 目标 SDK：35
- 使用自签名证书，首次安装如提示风险，确认后继续即可
- 若手机上装过旧版本，请先卸载再安装（每次构建签名证书会更新）

界面预览见 [`斤两换算_界面预览.png`](斤两换算_界面预览.png)。

## 源码与构建

源码在 `app/` 目录，为原生 Android 工程（Java + XML），不依赖 AndroidX / Gradle。

```bash
# 构建需要 JDK 17 与 Android SDK build-tools 34 / platform 35
# 修改 build_apk.sh 顶部的 JDK_DIR、BT、AJAR 路径后执行：
bash build_apk.sh
```

辅助脚本：
- `build_ref_html.py`：把资料 Markdown 转成 APP 内嵌的离线 HTML（`assets/reference.html`）
- `gen_icon.py`：生成应用启动图标 PNG（纯 Python，无外部依赖）

完整考证资料见 [`古代重量单位两与现代重量单位两演化资料.md`](古代重量单位两与现代重量单位两演化资料.md)。
